# Automatic Plant Watering System

Second-year academic project, B.Tech Electrical & Electronics Engineering, Rajiv Gandhi Institute of Technology, Kottayam.

An Arduino UNO based irrigation prototype that waters a plant automatically when the soil moisture drops below a set threshold.

## Components
- Arduino UNO
- Soil moisture sensor
- Relay module
- DC water pump

## How it works
1. The soil moisture sensor reads the moisture level of the soil.
2. The Arduino compares the reading with a set threshold.
3. If the soil is dry, the relay switches the pump on.
4. Once the moisture is back above the threshold, the pump switches off.

## What I learned
- Interfacing sensors and relay modules with Arduino
- Calibrating sensor thresholds to reduce water wastage
- Tuning actuation timing for low-maintenance plant care
